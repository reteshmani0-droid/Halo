Requirements

Windows

Windows 10 1809 or newer, or Windows 11. The installer is per user and does not need an administrator. Windows on ARM (Snapdragon, Dev Kit) needs the ARM64 build; the x64 build also runs under emulation.

macOS

macOS 12 or newer. Apple silicon needs the ARM64 build; Intel Macs need x64. Until the build is notarised, the first launch needs a right-click on the app and Open, once.

Linux

AppImage runs anywhere with chmod +x; the .deb is for Debian and Ubuntu on x64 or arm64. A desktop session is required: Halo has a window and a tray icon.

All systems

About 200 MB installed. A model endpoint and API key, entered in the app on first run. No account is required to use it.

After installing

  1. The first run opens a short setup: name, model, and whether to start with Windows.
  2. Hold Ctrl + Win anywhere to talk to it, or open the window and type.
  3. Optional: sign in on the dashboard and turn on the account in the app's settings, so this site can show the machine and cut its access if you need to.

The same three steps with the details, including what the first run asks for and where a model key comes from, are on the get started page.
