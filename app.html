Connecting another machine

  1. Install Halo on that machine and start it.
  2. Open Settings → Account there and paste this site's Supabase URL and anon key, then sign in with this same email.
  3. The machine appears here within a minute, with its name and what it is doing.

Only the app can start reporting; this page cannot add a machine, because a page cannot reach into a computer. If a machine is missing, its account switch is off or its sign-in failed — the app's settings show which.
