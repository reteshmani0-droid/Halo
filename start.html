Get started

Three steps, about five minutes. The first two are on your own machine and need nothing from this site; the third is what puts that machine on the dashboard.

  1. 1

    Download the build for this machine

    Halo installs on the computer it runs on, so take the build for that computer. The button is already the right one if you are reading this on it.

    Finding the right build…

    Every build, with its size and SHA-256, is on the download page.

  2. 2

    Install it and let it in on a model

    The Windows installer is per user, so it never asks for an administrator. On macOS the build is unsigned for now, so the first launch is a right click on the app and Open, once. On Linux, chmod +x the AppImage.

    The first run asks for a name, whether to start with Windows, and one thing that cannot be skipped: a model to talk to. Halo speaks to any OpenAI compatible endpoint, so an address and an API key from a provider you already pay for is enough.

    Where a key comes from

    Anything that serves the OpenAI chat API: OpenAI itself, a local llama.cpp or Ollama with its OpenAI shim, Groq, Together, DeepSeek, Moonshot, or a gateway of your own.

    Two buttons on the Model page are worth pressing before you trust it: Test connection, which sends one small message, and Load the model list, which asks the endpoint what it serves right now. Providers retire model names under you, and a retired one answers every message with a 404 until the name is changed.

    Then hold Ctrl + Win anywhere to talk to it, or open the window and type. It lives in the tray; closing the window does not quit it. Your key is stored on this machine and is never sent to this site.

  3. 3

    Sign in, so this site can see the machine

    Optional, and the app runs without it. With it, this site shows the machine, holds a copy of the conversation so you can read it from a phone, and can cut the machine's remote access off from anywhere.

    Create an account or sign in Go to the dashboard

    Then connect the machine itself: on the PC, open Settings, find the Account group, and switch on Report to this account. It asks for five things.

    The two values to paste in

    These are not secrets, and this page is where everybody gets them
    Project URL not configured
    Anon key not configured

    The anon key identifies the project; it does not authorise anything, because every table has row level security on and decides for itself what a key may read. Paste it into the app's Anon key field. Then fill in the same email and password you use here, press Sign in, and press Sync now: the machine appears on the dashboard within a minute.

From your phone

Read it on the dashboard

Signed in, /app works on a phone: the machines, what they have been doing, and the messages they reported. It is a copy of the conversation, not the live one, which stays on the machine.

Or talk to it over a bot

In the app there is a Bot page that connects a Telegram bot, so you can ask the machine something from outside the house with the app closed. Only the chats you pair with it are obeyed.

If something does not work

It answers everything with an error about the model

The endpoint, the key, or the model name. Press Test connection on the Model page: the message it returns is the one the provider sent, which is usually specific. A 404 almost always means the model name was retired; Load the model list replaces it with one that exists.

Nothing appears on the dashboard

The switch in the app's Account group has to be on, and the project URL and anon key have to be the ones above. The app shows its own reason under those fields: "not signed in" and "the project has no tables yet" are the two common ones, and both say what to do.

Windows says the publisher is unknown

The build is not code signed, so SmartScreen warns on the first run. Choose More info, then Run anyway. Installers on this site are listed with their SHA-256: if the hash matches, the file is the one that was built.

Ctrl + Win does nothing

Another app may already own the combination. The bar's own settings can change the shortcut, and the app's status line says when the global hook could not be installed.
